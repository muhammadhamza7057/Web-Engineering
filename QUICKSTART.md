# Quick Start (5 minutes)

## Prerequisites
- Node.js installed
- MongoDB running (local or Atlas)

## Terminal 1: Start Backend

```bash
cd OEL-WEB/backend
npm install
npm run dev
```

## Terminal 2: Start Frontend

```bash
cd OEL-WEB/frontend
npm install
npm run dev
```

## Access Application

- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost:5000

## Test It
